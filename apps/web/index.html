Your KaM files

Where the game gets its art

The client ships with no game data at all: the sprites, the maps and the rules tables are read from a KaM Remake copy you own. That is what keeps this site legal to host, and it is why the first screen asks for your files.

Own KaM Remake already? Two clicks on the setup screen.

On this PC

  1. Open the setup screen.
  2. Press Use my KaM folder and pick your KaM Remake folder.
  3. It is stored in this browser, so the next visit is straight to the map list.

On a PC without KaM

  1. Carry a KaM data pack (one .zip built from your own install).
  2. Press Use a KaM data pack (.zip) and pick it - no extraction, nothing uploaded.
  3. About 40 s later the atlases are built in the page and the game plays.

WORK-PC guide

Multiplayer

Rooms on the web

Host a room, share the link, and lockstep keeps every player's simulation identical. An AI slot can fill an empty seat, so a room works with one human too.

Needs an wss:// relay: see docs/HOSTING.md.

On your own network

Two commands start a server and a relay on the LAN: npm run serve:lan and npm run relay:lan. The lobby fills in the relay address itself, so guests only open the printed link.

Fair by construction

The simulation is fixed-point and deterministic, and every client applies the same command stream. A finished game can be hashed and compared, which is what a ladder needs to trust a result.
